Syntagmax

Git-Based Requirements Management System

Lightweight traceability, change detection, and impact analysis — fully native to your Git workflow.

Install from PyPI View on GitHub

Features

Everything you need for requirements engineering, right in your Git repository.

Git-Native

Built on git blame & history. No external databases — your repo is the single source of truth.

Metamodel DSL

Define artifact types, attributes, and trace rules declaratively with a simple, readable syntax.

Impact Analysis

Detect changes and propagate impact across the traceability tree automatically.

Traceability

Export full traceability matrices as CSV/TSV. Verify coverage with forward, reverse, and flat modes.

Project Metrics

Quantified coverage reports, TBD detection, and status tracking across your requirement baseline.

Task Generation

Automatically create verification tasks from impact analysis — track what needs review without manual bookkeeping.

How It Works

Syntagmax integrates directly into your Git-based workflows.

Point Syntagmax at your repository. It extracts artifacts, validates against your metamodel, computes traceability metrics, and generates comprehensive reports — all from the command line.
